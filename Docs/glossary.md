# Глоссарий

| Термин | Тип в коде | Значение |
|---|---|---|
| Сигнал | `ContextSignal` | Единица контекста от коннектора: вид (`SignalKind`), значение, интервал, источник, качество, атрибуты |
| Вид сигнала | `SignalKind` | Строковый идентификатор вроде `health.sleep.segment`; открытый — коннектор объявляет свои |
| Провайдер / коннектор | `ContextProvider` | Источник сигналов (HealthKit, питание, календарь…) |
| Статус провайдера | `ProviderStatus` | ready / noData / indeterminate / unauthorized / unavailable / timedOut / failed |
| Обязательство | `Commitment` | Занятое время: встреча, окно еды, тренировка, задача с фиксированным временем |
| Снапшот | `ContextSnapshot` | Всё, что видели движки в момент решения (сигналы, статусы, задачи, цели, обязательства, профиль) |
| Дневная сводка | `DailyHealthSummary` | Агрегаты здоровья за один день, `[SignalKind: Double]` |
| Baseline / норма | `Baseline`, `BaselineSet` | Личная норма по виду: медиана, разброс, число дней, надёжность (≥ 7 дней) |
| Ночь | `SleepNight` | Сон одной ночи после дедупликации источников: отбой, подъём, asleep, inBed, стадии |
| Состояние | `UserState` | Компоненты (сон, восстановление, нагрузка, топливо), энергия 0…1, уверенность, совет по нагрузке |
| Совет по нагрузке | `LoadAdvice` | reduce / normal / push / unknown |
| Бодрость | `Circadian` | Кривая по часу суток; `capacity = (0.5 + 0.5·energy)·alertness(t)` |
| Факт | `Fact` | Типизированное утверждение для текста («сон 6:03», «до созвона 80 мин») |
| План дня | `DayPlan` | Тайм-блоки, топ-задачи, отложенные, рекомендации; статус proposed / accepted / superseded |
| Блок | `PlanBlock` | Отрезок плана: focus / commitment / meal / rest |
| Разбор оценки | `ScoreBreakdown` | urgency, importance, goalAlignment, energyFit, durationFit, total |
| Рекомендация | `Recommendation` | Структурированный совет с rule-based текстом и опциональным LLM-объяснением |
| Нудж | `Nudge` | Момент-зависимый вопрос с готовым текстом, действиями и условиями отмены |
| Фидбек | `UserFeedback` | Оценка дня, принятие плана, ответ на нудж, перенос задачи, отметка еды |
| Калибровка | `Calibration` | Что выучил Feedback Engine: смещение энергии, пороги, ёмкость, множитель оценок, grace нуджей |
| Конфиг движков | `EngineConfig` | Константы продукта: веса scoring, веса компонент, окна, лимиты |
| Запись дня | `DayRecord` | Документ дня: снапшот, состояние, план, нуджи, фидбек (JSON-блоб) |
| Профиль | `UserProfile` | Рабочий день, тихие часы, время вечернего опроса, целевой сон |
| Профиль питания | `NutritionProfile` | Диета, ограничения, продукты, теги заболеваний, окна еды |
| Отметка еды | `MealLog` | «Поел» — вид приёма пищи и время |
| Контекст времени | `TimeContext` | now + календарь с явной зоной + локаль; единственный источник времени в ядре |
| Анализатор состояния | `StateAnalyzer` | Точка расширения: новый компонент состояния |
| Правило плана | `PlanRule` | Точка расширения: пост-обработка плана и рекомендации |
| Правило нуджей | `NudgeRule` | Точка расширения: новый вид нуджа |
| Объяснитель | `Explainer`, `TextRenderer` | Превращает факты в русский текст; rule-based всегда, LLM опционально |
| Задача | `LineaTask` | `date` (день), `deadline` (срок), `scheduledStart` (фиксированное время), длительность, сложность, цель |
| Цель | `LineaGoal` | Горизонт неделя/месяц, дата начала, активность, прогресс |
| Сложность | `CognitiveDemand` | light 0.3 / normal 0.6 / deep 0.9 |
| Итог дня, чек-ин | `CheckInEntry` | Рассказ о дне голосом или текстом и подтверждённый итог: закрытое, незакрытое, сверх плана, объём, оценка, силы |
| Разбор итога | `CheckInExtraction` | Что понял разборщик (правила или модель) до подтверждения человеком |
| Черновик итога | `CheckInDraft` | Экран «Проверь»: галочки, объём, оценка, факты для памяти, перенос на завтра |
| План против факта | `DayReportSummary` | Доля минут плана, пришедшаяся на закрытые задачи; учит ёмкость дня |
| Выжимка дня | `CheckInEntry.digest` | Строка вместо рассказа в запросах к модели: «22.09, пн: сделано 3 из 5…» |
| Память | `UserMemory`, `MemoryFact` | До 40 устойчивых фактов о человеке с источником, подтверждениями и закреплением |
| Кандидат в память | `MemoryCandidate` | Предложение запомнить — от «запомни, что…» или модели; фактом становится после консолидации |
| Консолидация | `MemoryConsolidator` | Слияние похожего, забывание разового, вытеснение слабого сверх лимита |
| Контекст пользователя | `UserContextBuilder`, `UserContext` | Блок памяти для запроса к модели в пределах бюджета токенов |
| Распознаватель | `SpeechTranscribing`, `Transcript` | Голос → текст на телефоне: модель GigaAM или диктовка iPhone |
| Быстрый ввод | `QuickTaskDraft`, `QuickTaskResolution` | Новая задача одной строкой: название + чипы; чип сильнее сказанного, сказанное сильнее значения по умолчанию |
| Разбор строки | `QuickTaskParser`, `QuickTaskParse` | Набранная или надиктованная строка → название, день, срок, время, длительность, приоритет, цель |
| Когда | `TaskDay` | Сегодня / завтра / на неделе / конкретный день / без даты; превращается в `date` и `deadline` задачи |
| Связь с целью | `GoalLinker`, `GoalLink` | Явная (человек), подсказка «Похоже, относится к: … [Связать]» или автоматическая (заложена, выключена) |
| Чип | `TaskChip` | Параметр под строкой ввода; серый — значение не задавали |
| Тип задачи | `TaskKind` | Внутренний `task_type`: шаг к цели, обязательство, быт и дела, рутина, входящее, разовое; в основном интерфейсе не виден |
| Классификатор | `TaskClassifier`, `TaskClassification` | Тип по выбору человека, связи с целью, словам названия, времени; с уверенностью и причиной |
| Оценка длительности | `TaskEstimate` | Оценка человека или обычная для типа (15–60 мин) |
| Важность | `PriorityAssessment.importance`, `ImportanceFactors` | `importance_score`: насколько задача важна вообще — приоритет, цель, срок, тип, ждущие задачи, переносы |
| Уместность сейчас | `PriorityAssessment.action`, `ActionFactors` | `action_score`: насколько разумно браться прямо сейчас — окно, силы, срок, день, ритм, баланс; 0, если нельзя |
| Движок приоритизации | `PriorityEngine`, `PriorityContext` | Две оценки задачи в момент; ими пользуются план и «Сейчас» |
| Сейчас, действие | `NextActionUseCase`, `NextAction` | Одно действие, которое Linea предлагает в эту минуту: что, сколько, почему; плюс до трёх в «Другое». Не задача, а предложение по задаче |
| Начатое действие | `ActionStart`, `FeedbackKind.actionStarted` | «Начать»: отклик в дне; пока действие идёт, план держит его время, задача не меняется |
| Без даты, входящие | `InboxReview`, `LineaTask.inboxReviewedAt` | Открытые задачи без дня, срока и времени; Linea ставит пару из них в свободное время и предлагает разобрать |
| Разбор «Без даты» | `InboxReview.Choice`, `InboxReview.Suggestion` | По одной задаче: Сегодня / Завтра / На неделе / Оставить без даты / Удалить, с подсказкой Linea |
| «Я поняла цель так» | `GoalUnderstanding`, `GoalAnalyzing` | Новая цель после разбора: название, «Сейчас», «Результат», признаки успеха, срок; создаётся по «Всё верно» |
| Уточняющий вопрос | `GoalQuestion` | Один за раз: «Как поймём, что цель достигнута?», потом «С чего начинаем?»; можно пропустить |
| Перенести | `TaskReschedule` | Куда можно перенести задачу (сегодня, завтра, на неделе, на следующей неделе, свой день, без даты) и что станет с её временем и сроком |
| Действия в строке | `TaskRowActions`, `SwipeActionsRow`, `TaskActionsMenu` | Свайп вправо — «Готово», влево — «Перенести», долгое нажатие — «Изменить», «Привязать к цели», «Изменить приоритет», «Удалить» |
| Сейчас и результат цели | `LineaGoal.currentState`, `targetState`, `successCriteria` | `current_state`, `target_state`, `success_criteria`: с чего начинаем, что будет, как проверить |
| Сначала нужно | `LineaTask.blockedBy`, `TaskDependencies` | Задачи, без которых эту не начать; план ставит её после них |
| Переносы | `LineaTask.deferralCount`, `TaskDeferral` | Сколько раз задачу, которую пора было делать, сдвинули на потом |
| Важность цели | `LineaGoal.priority` | `goal_importance`: низкая / средняя / высокая |
| Поля человека | `TaskField`, `LineaTask.userFields` | Параметры задачи, которые человек задал сам: сказал при создании, выбрал в чипе или поменял потом; Linea их не перезаписывает |
| Чьё значение | `TaskOwnership`, `TaskProposal` | Правка человека делает поле его; сама Linea меняет задачу только предложением и только в своих полях |
| Опора на слова | `QuickTaskParse.grounded(in:)`, `QuickTaskParse.Recognized` | У каждого значения разбора — кусок строки, из которого оно взято; без опоры значение не принимается |
| Строка задачи | `QuickTaskText.summary` | «Завтра · до 12:00 · ~1 ч 30 мин · Высокий» — только заданное, без значений по умолчанию |
| Причина «Сейчас» | `NowReason`, `NowReasoner`, `Fact.nowReason` | Одна короткая фраза, почему Linea предлагает это действие сейчас: срок, план, окно, цель, приоритет… без баллов |
| Главная цель | `NowReasoner.mainGoal` | Самая важная из активных целей, при равной важности — с ближним сроком |
| Поиск цели задачи | `ConceptGoalMatcher`, `GoalConcepts`, `GoalConcept` | Похожа ли задача на цель: понятия вместо слов, цель целиком (название, результат, рассказ); не уверена — молчит |
| Подсказка цели | `GoalSuggestionRow`, `GoalLinker.suggestion` | «Похоже, относится к: … [Связать]» в быстром вводе и в карточке задачи; связывает только человек |
