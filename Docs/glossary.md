# Глоссарий

| Термин | Тип в коде | Значение |
|---|---|---|
| Сигнал | `ContextSignal` | Единица контекста от коннектора: вид (`SignalKind`), значение, интервал, источник, качество, атрибуты |
| Вид сигнала | `SignalKind` | Строковый идентификатор вроде `health.sleep.segment`; открытый — коннектор объявляет свои |
| Провайдер / коннектор | `ContextProvider` | Источник сигналов (HealthKit, питание, календарь…) |
| Статус провайдера | `ProviderStatus` | ready / noData / indeterminate / unauthorized / unavailable / timedOut / failed |
| Обязательство | `Commitment` | Занятое время: встреча, окно еды, тренировка, задача с фиксированным временем |
| Снапшот | `ContextSnapshot` | Всё, что видели движки в момент решения (сигналы, статусы, задачи, цели, обязательства, профиль) |
| Дневная сводка | `DailyHealthSummary` | Агрегаты здоровья за один день, `[SignalKind: Double]` |
| Baseline / норма | `Baseline`, `BaselineSet` | Личная норма по виду: медиана, разброс, число дней, надёжность (≥ 7 дней) |
| Ночь | `SleepNight` | Сон одной ночи после дедупликации источников: отбой, подъём, asleep, inBed, стадии |
| Состояние | `UserState` | Компоненты (сон, восстановление, нагрузка, топливо), энергия 0…1, уверенность, совет по нагрузке |
| Совет по нагрузке | `LoadAdvice` | reduce / normal / push / unknown |
| Бодрость | `Circadian` | Кривая по часу суток; `capacity = (0.5 + 0.5·energy)·alertness(t)` |
| Факт | `Fact` | Типизированное утверждение для текста («сон 6:03», «до созвона 80 мин») |
| План дня | `DayPlan` | Тайм-блоки, топ-задачи, отложенные, рекомендации; статус proposed / accepted / superseded |
| Блок | `PlanBlock` | Отрезок плана: focus / commitment / meal / rest |
| Разбор оценки | `ScoreBreakdown` | urgency, importance, goalAlignment, energyFit, durationFit, total |
| Рекомендация | `Recommendation` | Структурированный совет с rule-based текстом и опциональным LLM-объяснением |
| Нудж | `Nudge` | Момент-зависимый вопрос с готовым текстом, действиями и условиями отмены |
| Фидбек | `UserFeedback` | Оценка дня, принятие плана, ответ на нудж, перенос задачи, отметка еды |
| Калибровка | `Calibration` | Что выучил Feedback Engine: смещение энергии, пороги, ёмкость, множитель оценок, grace нуджей |
| Конфиг движков | `EngineConfig` | Константы продукта: веса scoring, веса компонент, окна, лимиты |
| Запись дня | `DayRecord` | Документ дня: снапшот, состояние, план, нуджи, фидбек (JSON-блоб) |
| Профиль | `UserProfile` | Рабочий день, тихие часы, время вечернего опроса, целевой сон |
| Профиль питания | `NutritionProfile` | Диета, ограничения, продукты, теги заболеваний, окна еды |
| Отметка еды | `MealLog` | «Поел» — вид приёма пищи и время |
| Контекст времени | `TimeContext` | now + календарь с явной зоной + локаль; единственный источник времени в ядре |
| Анализатор состояния | `StateAnalyzer` | Точка расширения: новый компонент состояния |
| Правило плана | `PlanRule` | Точка расширения: пост-обработка плана и рекомендации |
| Правило нуджей | `NudgeRule` | Точка расширения: новый вид нуджа |
| Объяснитель | `Explainer`, `TextRenderer` | Превращает факты в русский текст; rule-based всегда, LLM опционально |
| Задача | `LineaTask` | `date` (день), `deadline` (срок), `scheduledStart` (фиксированное время), длительность, сложность, цель |
| Цель | `LineaGoal` | Горизонт неделя/месяц, дата начала, активность, прогресс |
| Сложность | `CognitiveDemand` | light 0.3 / normal 0.6 / deep 0.9 |
| Итог дня, чек-ин | `CheckInEntry` | Рассказ о дне голосом или текстом и подтверждённый итог: закрытое, незакрытое, сверх плана, объём, оценка, силы |
| Разбор итога | `CheckInExtraction` | Что понял разборщик (правила или модель) до подтверждения человеком |
| Черновик итога | `CheckInDraft` | Экран «Проверь»: галочки, объём, оценка, факты для памяти, перенос на завтра |
| План против факта | `DayReportSummary` | Доля минут плана, пришедшаяся на закрытые задачи; учит ёмкость дня |
| Выжимка дня | `CheckInEntry.digest` | Строка вместо рассказа в запросах к модели: «22.09, пн: сделано 3 из 5…» |
| Память | `UserMemory`, `MemoryFact` | До 40 устойчивых фактов о человеке с источником, подтверждениями и закреплением |
| Кандидат в память | `MemoryCandidate` | Предложение запомнить — от «запомни, что…» или модели; фактом становится после консолидации |
| Консолидация | `MemoryConsolidator` | Слияние похожего, забывание разового, вытеснение слабого сверх лимита |
| Контекст пользователя | `UserContextBuilder`, `UserContext` | Блок памяти для запроса к модели в пределах бюджета токенов |
| Распознаватель | `SpeechTranscribing`, `Transcript` | Голос → текст: xAI или iPhone |
