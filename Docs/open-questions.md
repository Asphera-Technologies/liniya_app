# Открытые вопросы заказчику

Для каждого вопроса указан **дефолт**, с которым работа продолжается, не
дожидаясь ответа. Ответы вписываются в колонку «Ответ», после чего решение
переносится в `Docs/decisions.md`. Отсортировано по влиянию на реализацию.

| № | Вопрос | Дефолт, по которому идёт работа | Ответ |
|---|---|---|---|
| 1 | **Где живёт Intelligence.** Верно ли, что State/Decision Engine считаются на устройстве, а сервер в v1 не участвует (макс. прокси к LLM)? Или ожидается серверный движок, считающий состояние и рекомендации для всех пользователей? Существует ли уже какой-то веб-бэкенд (в макете есть «Корзина 277 ₽», «Меню на неделю»)? | На устройстве; сервер — только будущий прокси `POST /v1/explain`. Если нужен серверный движок — это меняет язык, контракт снапшотов и объём v1 | |
| 2 | **Apple Watch у тестового пользователя.** Есть ли часы (или другой источник сна/HRV в Apple Health) с историей ≥ 7 дней? Без них не будет ни сна, ни HRV, и wow-сценарий не воспроизвести | Считаем, что есть. Без данных приложение честно планирует «по времени и приоритетам» | |
| 3 | **LLM.** Допустимо ли, что текст формулирует on-device модель iOS 26 (FoundationModels) с fallback на шаблоны, а облако — позже и по согласию? «AI: Grok» в макете профиля — требование или заглушка? | On-device + шаблоны; облако позже; «Grok» — заглушка | |
| 4 | **Семантика времени задачи.** `date` — день, когда делать; `deadline` — срок (с временем, опционально); `scheduledStart` — фиксированное время, которое делает задачу обязательством; план задачи не меняет. Так? | Да | |
| 5 | **Важность, длительность, сложность.** Три уровня важности (низкая/обычная/важно), длительность чипами 15/30/45/60/90/120 мин, сложность вручную «Лёгкая/Обычная/Сложная» (0.3/0.6/0.9), по умолчанию «Обычная». AI-оценка сложности — только подсказка позже? | Да | |
| 6 | **Цели.** Горизонт неделя/месяц от даты начала; лимит 1–3 активных — мягкий (предупреждение); связь задача↔цель явная в редакторе + подсказка по совпадению слов; прогресс — ручной слайдер (как сейчас) или из закрытых связанных задач? | Мягкий лимит; явная связь + подсказка; прогресс из задач, если связанные есть, иначе слайдер | |
| 7 | **Доступное время.** Рабочий день 09:00–21:00, тихие часы 22:00–08:00 в профиле; обязательства в v1 — задачи с временем и окна еды; календарь (EventKit) — следующий коннектор. Так? | Да | |
| 8 | **Baseline.** Личная норма — медиана за 28 дней, сравнение «с обычным» только при ≥ 7 днях, до этого «собираю базу: день N из 7». Устраивает? | Да | |
| 9 | **Питание в v1.** Профиль (диета, можно/нельзя, продукты, заболевания как теги без интерпретации) + окна еды + кнопка «Поел» + рекомендации «обед легче / перекус перед тренировкой». Без каталога, рецептов, калорий. Есть ли готовая база продуктов или сервис? | Только профиль, без базы | |
| 10 | **Уведомления.** Допустимы локальные уведомления с кнопками («Закрываем сейчас / Переносим», три оценки вечером), запрос разрешения при первом «Принять план», не более 3 нуджей в день? Фоновый режим (BGTaskScheduler) — не в v1? | Да; фон — v1.1 | |
| 11 | **Фидбек.** Вечерние три кнопки калибруют строгость оценки состояния (смещение энергии, пороги «снизить/можно больше»), частоту нуджей; веса приоритизации не обучаются. Достаточно для v1? | Да | |
| 12 | **Онбординг.** Минимум: подключить Apple Health, рабочие часы, первая цель. Остальное — из Profile. Или онбординг не нужен вовсе в v1? | Минимальный, через существующие CTA и Profile | |
| 13 | **Аккаунты и синхронизация.** Один пользователь, одно устройство, всё локально, без iCloud? | Да; поля `updatedAt` закладываются на будущее | |
| 14 | **Сборка на Mac.** Кто и как часто собирает проект в Xcode и запускает на iPhone? Можно ли выделить macOS-раннер для CI (GitHub Actions `macos-26` или self-hosted)? | Заказчик собирает по чек-листу из `Docs/roadmap.md`; CI на Linux блокирующий, macOS — вручную | |
| 15 | **Демо-режим.** Допустим ли `#if DEBUG` провайдер с записанным сценарием («сон 6:03, HRV ниже обычного») для показа без часов, при правиле AGENTS.md о фейковых данных? | Да, только в DEBUG, в release не компилируется | |
| 16 | **Срок и приёмка MVP.** К какой дате нужно демо и что считается принятым (утренний сценарий на вашем iPhone с реальными данными)? | Итерации по неделям; приёмка — сценарий из `Docs/product.md` | |
| 17 | **Язык.** Только русский в v1 (тексты, шаблоны, промпты)? | Да; строки собраны в одном месте для будущей локализации | |
