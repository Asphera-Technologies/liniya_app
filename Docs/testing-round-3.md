# Инструкция для тестировщика: быстрые задачи и приоритизация

Для того, кто проверяет новую версию на своём iPhone. Программистом быть не
нужно, понадобится Mac с Xcode — как в прошлых раундах.

**Что нового.** Четыре вещи, сделанные по порядку:

1. **Быстрая задача.** Кнопка «+» рядом с «Задать вопрос Linea» на любом
   экране. Достаточно названия и «Добавить» — остальное необязательно.
   Задачу можно надиктовать: «завтра в 10, на полтора часа, важно» само
   встаёт в параметры.
2. **Чипы вместо формы.** Под строкой — «Сегодня ~30 мин Средний» (и цель,
   если цели есть). Тап по чипу — маленький выбор. Полной формы при создании
   больше нет; карточка задачи — только для правки.
3. **Тип задачи.** Linea сама понимает, что это: шаг к цели, обязательство,
   быт, рутина, входящее, разовое. В интерфейсе типа почти не видно — только
   внизу карточки задачи.
4. **Приоритизация.** У задачи две оценки: насколько она важна и насколько
   разумно браться за неё прямо сейчас. На «Сегодня» появился блок «Сейчас».

Зачем это и как устроено — `Docs/intelligence.md`, разделы 14–16, читать не
обязательно. Проверка займёт около часа.

## Установка

Всё как в `Docs/testing-round-2.md`, раздел «Установка», только версия — в
отдельной ветке, пока её не влили в `main`:

```bash
cd liniya_app
git fetch
git checkout feature/ios-quick-task-priority
git pull
```

Потом в Xcode снова «Play». Задачи и цели из прошлой версии должны остаться
на месте — это тоже проверка (пункт 14).

Если приложение закрылось само — пришли отчёт о сбое: «Настройки» →
«Конфиденциальность и безопасность» → «Аналитика и улучшения» → «Данные
аналитики», файл, который начинается с `Linea`.

## Проверки

### Быстрая задача

**1. Одно название.** На «Сегодня» нажми «+» справа от «Задать вопрос Linea».
Снизу выезжает невысокий лист, клавиатура уже открыта. Напиши «Купить
продукты» и нажми «Готово» на клавиатуре (или ✓ сверху).
*Должно быть:* лист закрылся, в «Плане» задача на сегодня. На всё — пара
секунд. Чипы до сохранения были серые: «Сегодня», «~30 мин», «Средний».

**2. Параметры словами.** Снова «+», напиши: «Отчёт завтра в 10 на полтора
часа, важно».
*Должно быть:* пока пишешь, чипы чернеют и меняются: «Завтра, 10:00», «~1 ч
30 мин», «Высокий». Сохранится задача с названием «Отчёт» — слова про день,
время, длительность и важность из названия уходят.
Ещё варианты, по одному: «Оплатить квартиру до 25 числа», «Разобрать шкаф на
выходных», «Подготовить релиз на неделе», «Книгу почитать когда-нибудь».

**3. Голосом.** «+» → кнопка микрофона в строке → скажи «позвонить маме
завтра в семь вечера» → нажми кнопку ещё раз.
*Должно быть:* «Распознаю на телефоне…», потом в строке текст, чипы
«Завтра, 19:00». Проверь ✓ — задача «Позвонить маме». Микрофон на клавиатуре
(диктовка iPhone) тоже работает — текст разбирается так же.

**4. Цель.** Нужна активная цель, например «Запустить MVP Linea».
- Напиши «Подготовить релиз для цели MVP» — чип цели сразу чёрный, с её
  названием.
- Напиши «Запустить лендинг» — чип цели серый, «Запустить MVP Linea?» с
  искоркой. Тап → «Похоже, к цели…» → связывается. Без нажатия задача
  сохранится без цели: Linea только подсказывает.

### Чипы

**5. Маленькие выборы.** «+», любое название, потом по чипам:
- «Когда»: Сегодня / Завтра / На неделе / Выбрать дату (календарь — тап по дню
  сразу выбирает), ниже «Срок…» (дата и время) и «Без даты»;
- «Сколько»: 15 / 30 / 45 мин / 1 час / Другое (колесо от 5 минут до 8 часов);
- «Приоритет»: Низкий / Средний / Высокий;
- «Цель» — только если цели есть.
*Должно быть:* не больше четырёх чипов, выбранное — чёрным. Чип сильнее
сказанного: напиши «Отчёт сегодня», выбери «Завтра» — задача на завтра.

**6. Формы создания больше нет.** В «Плане» «+ Задача» открывает тот же
быстрый лист. Тап по существующей задаче открывает её карточку «Задача» — там
все параметры, как раньше.

**7. Без копий.** «+», название, быстро дважды нажми ✓. Задача одна.

### Тип задачи

**8. Linea понимает тип.** Создай «Оплатить интернет», «Ответить Ивану»,
«Подготовить стратегию». Открой карточку каждой — в самом низу «Тип задачи»:
«Быт и дела», «Входящее», «Шаг к цели», серым («определяет Linea»). Поменяй
тип — станет чёрным и сохранится.

**9. Длительность по типу.** Создай «Ответить Ивану» без длительности — чип
был «~15 мин», в плане дня блок на 15 минут. «Подготовить стратегию» — «~1 ч».

### Приоритизация

**10. «Сейчас» — пример из постановки.** Создай:
- «Встреча с клиентом в 15:50 на 30 минут» — подставь время через 20 минут от
  текущего (или событие в календаре, если он подключён);
- «Подготовить стратегию», высокий, 1 час 30 минут, сегодня;
- «Ответить на письма», 15 минут, сегодня.
*Должно быть:* на «Сегодня» блок «Сейчас»: «Сейчас — «Ответить на письма».
До «Встреча с клиентом» 20 мин, а на «Подготовить стратегию» нужно 1 ч 30 мин —
её лучше после.» Во время встречи блок пропадает. После встречи — «Сейчас —
«Подготовить стратегию».» Блок обновляется сам раз в минуту, пока экран
открыт. «Главное сегодня» всё это время — самое важное: «Подготовить
стратегию».

**11. Сначала нужно.** Создай «Собрать данные» и «Написать отчёт» (высокий).
В карточке «Написать отчёт» → «Сначала нужно» → выбери «Собрать данные».
*Должно быть:* в плане дня «Написать отчёт» стоит после «Собрать данных», хотя
он важнее. В карточке «Собрать данные» нельзя выбрать «Написать отчёт» —
петли не получится.

**12. Важность цели.** Открой цель → «Важность» → «Высокая». Её задачи
поднимаются в плане и в «Главное сегодня».

**13. Переносы.** Ответь «Переносим» на напоминание или передвинь задачу с
сегодня на завтра. Внешне ничего нового — Linea молча считает, сколько раз
задачу переносили, и с каждым разом поднимает её важность. Проверь только,
что перенос работает как раньше.

### Ничего не сломалось

**14.** Задачи и цели из прошлой версии на месте. Утренний план, «Принять
план», напоминание «План немного отстаёт», вечерний итог дня — работают как в
прошлом раунде.

## Что прислать

- По каждой проверке: «ок» или что пошло не так, со скриншотом.
- Если что-то не так с параметрами из текста — точную фразу, которую писал
  или говорил.
- «Профиль» → «Диагностика» → «Отправить» после проверок 3, 9 и 10: там
  видно, как Linea разобрала голос и какие типы задач увидела.
