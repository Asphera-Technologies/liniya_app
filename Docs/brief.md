## Задачи первого этапа («бэк» Linea)

### Аналитика HealthKit
- сон;
- шаги;
- пульс;
- HRV;
- тренировки.

### Tasks
- название;
- дедлайн;
- важность;
- примерная длительность.

### Goals
- 1–3 активные цели;
- горизонты: неделя и месяц.

### Время
- текущий момент;
- доступное время сегодня.

Календарь можно подключить следующим коннектором.

AI говорит:

> закрыл КП, а разработку оставил на вторую половину дня.»

## Decision Engine

Получает: UserState + Tasks + Goals + Time.
Отвечает на вопрос: **WHAT SHOULD THE USER DO NEXT?**

Пример scoring задачи:

```text
Priority =
    urgency
  + importance
  + goalAlignment
  + energyFit
  + durationFit
```

`energyFit` — необычная для task manager вещь. Например:

- Сделать презентацию — CognitiveDemand = 0.9
- Ответить на письма — CognitiveDemand = 0.3

Если Energy = 0.35, Linea может перестроить последовательность.

## Первый wow-сценарий (один use-case)

### Утро
Пользователь открывает Linea. Она уже знает:
- Сон: 6:03
- Recovery: ниже обычного

Сегодня:
- 10:00 задача A
- 13:00 задача B
- 17:00 тренировка

Цель: запустить MVP Linea.

И сразу:
> Доброе утро. Сегодня нагрузку лучше немного снизить.
> У тебя есть 3 приоритетных действия. Самую сложную работу предлагаю сделать до 12:00.

Кнопка: **Принять план** → появляется Today.

### В течение дня
Linea замечает: 14:30, task A не выполнена, и говорит:
> План немного отстаёт. До следующего обязательства осталось 1 ч 20 мин.
> Закрываем презентацию сейчас или переносим?

### Вечером
Три нажатия: «Как прошёл день?» — [Отлично] [Нормально] [Тяжело].
Это отправляется обратно в Feedback Engine.

## Ключевая абстракция — ContextProvider

```swift
protocol ContextProvider {
    func fetchContext() async throws -> [ContextSignal]
}
```

Тогда HealthKitProvider, TasksProvider, CalendarProvider, NutritionProvider,
LocationProvider, ScreenTimeProvider становятся коннекторами:

```text
            HealthKit
                ↓
Calendar → Context Engine ← Tasks
                ↑
             Nutrition
                ↑
              Gmail
```

Это уже очень похоже на будущую платформенную архитектуру Linea.

## Комментарий заказчика (голосом)

- Структура репозитория подготовлена совместно с ChatGPT; наброски выше — тоже.
- Нужно посмотреть со своей точки зрения и продумать реализацию так, чтобы не
  переделывать по 10 раз, а подключать новые коннекторы; масштабировать
  архитектуру правильно. «Одно дело, что ChatGPT накидал, — надо действительно
  подумать». Уточняющие вопросы по продукту приветствуются.
- Более точно сформулированные задачи:
  - task management: создание задач с базовыми параметрами (приоритет и те, что
    перечислены выше);
  - создание целей — недельных и месячных;
  - здесь включается AI: анализировать, насколько задачи «мэтчатся» с целями,
    умная приоритизация;
  - питание: продумать, как загружать диеты (что можно / что нельзя), список
    рекомендованных продуктов, возможно список заболеваний — но по минимуму.
- Главное: чтобы один–два юзкейса отработали с реальными показателями
  (расчёт показателей, аналитика сна) и появились связи между задачами,
  показателями здоровья (HealthKit) и питанием.
- **Критерий успеха первой версии:** задачи, цели, показатели здоровья и
  питание как-то взаимодействуют между собой, и между ними появляются связи.
- Документацию, цели и шаги вести отдельно, чтобы весь контекст по проекту
  можно было поднять и понять.
- Коммиты: однострочные, conventional.
